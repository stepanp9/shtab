Учебный прототип помощника для самостоятельных тренировок в зале. Тренер показывает план, Напарник ведёт по тренировке, а Аналитик показывает сводку по журналу.

[Открыть прототип](https://stepanp9.github.io/shtab/)

## Запуск

Скачайте файлы и откройте index.html в браузере. Для запуска через локальный сервер выполните из корня проекта команду из блока ниже.

~~~sh
python -m http.server 8000
~~~

Затем откройте [http://localhost:8000](http://localhost:8000). Страница работает на HTML, CSS и JavaScript без сборки. Действия выполняются в браузере на примере демонстрационного профиля.

## Сценарий

1. Откройте профиль и перейдите к плану на сегодня.
2. Если времени меньше, откройте пересборку и выберите сокращённую тренировку.
3. Начните занятие, запишите подход и завершите тренировку.
4. Откройте «Прогресс» и посмотрите недельную сводку.
